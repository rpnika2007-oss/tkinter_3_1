## Описание проекта

Программа представляет собой графические часы, разработанные на Python с использованием библиотеки Tkinter.

## Функциональность

- Аналоговые часы со стрелками.
- Отображение текущего времени и даты.
- Приблизительная визуализация фазы Луны.
- Секундомер с функциями запуска, остановки, сброса и отсечек.

## Требования

- Python 3.9+
- Tkinter (стандартная библиотека Python)

## Запуск программы

1. Установить Python.
2. Скачать или клонировать репозиторий.
3. Запустить команду:

```bash
python main.py
```

- `main.py` — основной код программы.
